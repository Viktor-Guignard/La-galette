Autoriser cet ordinateur

Tout le monde peut consulter les cartes. Pour enregistrer et publier depuis cet ordinateur (ou ce téléphone), il faut l'autoriser une fois : ouvrez simplement le lien d'activation que Viktor vous a envoyé (il commence par l'adresse de l'éditeur et se termine par « #jeton=… »). C'est tout.

Réservé à l'administrateur : créer la clé d'accès
  1. Ouvrez github.com/settings/personal-access-tokens/new (connecté à votre compte GitHub).
  2. Token name : « carte galette » — Expiration : 1 an.
  3. Repository access : Only select repositories → choisissez La-galette.
  4. Permissions → Repository permissions → Contents : Read and write.
  5. Bouton Generate token, copiez le jeton (commence par github_pat_…) et collez-le ci-dessous.
Ce jeton ne donne accès qu'au repo de la carte, rien d'autre. À coller une fois par ordinateur (PC du resto, Mac, etc.).
✨ Lien d'activation — pour vos autres ordinateurs et téléphones

Copiez ce lien et ouvrez-le sur le PC du resto, le Mac, le téléphone… : l'appareil est autorisé tout de suite. Gardez-le pour vous (il donne le droit de modifier les cartes).
